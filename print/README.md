# Beju print files

Not part of the website: Netlify only publishes `beju-site/`.

- `labels/`: bag labels for plain kraft valve pouches (front label for each coffee, 100×125 mm; back 一括表示 label, 70×92 mm). See `labels/README.txt`.
- `bags-200g/`: printed-bag artwork (130×215 mm trim, 3 mm bleed, CMYK). The single origins read 200 g; the Casablanca Blend reads 250 g.
- `label-source/`: the scripts that generate the labels (`labels.py` writes the HTML, `render.js` renders the PDFs with Chromium).

Plain bags for the labels: コーヒー袋net (coffee-fukuro.net) No.50385 (kraft) or No.50871 (white, aluminium-coated), 160×230(200)×70 mm, about 200 g, valve on the back.
